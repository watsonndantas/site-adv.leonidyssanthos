# Site Institucional — Advocacia Leonidys Santhos

Landing page institucional desenvolvida para escritório de advocacia, com foco em apresentação de áreas de atuação, atendimento e captação de clientes.

🔗 **Site ao vivo:** https://advleonidyssanthos.com.br

## ⚙️ Tecnologias

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

## ✨ Funcionalidades

- Apresentação institucional do escritório e áreas de atuação
- Seção de contato e call-to-action para atendimento
- Design responsivo para desktop e mobile
- Deploy contínuo via GitHub Pages com domínio próprio

## 🚀 Como rodar localmente

```bash
git clone https://github.com/watsonndantas/site-adv.leonidyssanthos.git
cd site-adv.leonidyssanthos
# abrir index.html no navegador
```
