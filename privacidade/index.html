Política de Privacidade

Como este site trata seus dados pessoais, em linguagem simples.

Quem é o responsável

Este site pertence ao escritório Leonidys Santhos Advocacia, do advogado Leonidys Santhos (OAB/PI 21.257), com endereço na Rua Padre Marcos, 1748 – Matinha, Teresina-PI, CEP 64002-020. Dúvidas sobre privacidade podem ser enviadas para adv.leonidys.santhos@gmail.com.

Quais dados são tratados

  • Formulário de contato: o site não armazena o que você digita. Ao clicar em enviar, a mensagem é aberta no seu WhatsApp, e só é enviada se você confirmar o envio por lá.
  • Contato pelo WhatsApp ou e-mail: as informações que você enviar são usadas apenas para responder e, se houver contratação, para a prestação do serviço jurídico, com o sigilo profissional previsto no Estatuto da Advocacia.
  • Medição de audiência: se você aceitar no aviso de cookies, usamos o Google Analytics para contar visitas e cliques nos botões de contato, de forma agregada. Se recusar, essa medição não é carregada.

Seus direitos

Pela Lei Geral de Proteção de Dados (Lei 13.709/2018, art. 18), você pode pedir confirmação, acesso, correção ou eliminação dos seus dados, entre outros direitos, pelo e-mail acima. Para retirar o consentimento de medição, basta limpar os dados de navegação deste site no seu navegador.
